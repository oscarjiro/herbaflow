# diseases ETL — AI Instructions

## Non-obvious conventions

**Provenance lives under `source:` in settings.yml, not at root level.** The normalize step reads provenance like this:

```python
source_cfg = settings.get("source", {})
batch_id   = source_cfg.get("batch_id", "")
source_name = source_cfg.get("name", "")
source_url  = source_cfg.get("url", "")
```

Do NOT read `settings.get("batch_id")` or `settings.get("source_name")` — those keys don't exist at root. This nesting matches the shared settings schema documented in `etl/CLAUDE.md`.

**Input is a curated seed file, not a scraped source.** `01_normalize/in/disease_seed.csv` is hand-curated, not generated by an upstream ETL stage. Changes to the seed require a full re-run of all 5 stages.

**Ontology mapping is seed-preferred, not inference-first.** `02_map_ontology` checks for ontology IDs already present in the seed columns (e.g. `doid_id`, `mesh_id`) before consulting OLS4 online. This is intentional — avoids overwriting curated mappings with automated guesses.

**OLS4 lookup is optional.** Controlled by `ontology.online_lookup: true` in `settings.yml`. Disable for offline/CI runs. Timeout and max results are also in `settings.yml` under `ontology.request_timeout` and `ontology.max_results`.

**Near-duplicate threshold is settings-driven.** `validation.near_duplicate_threshold` in `settings.yml` (currently `0.92`). Do not hardcode `0.92` in `04_validate/run.py` — it reads from config.

**UUID namespace in `utils.py` is frozen.** `DISEASE_NS` produces all `disease_id` values. Changing it invalidates all existing IDs and breaks FK integrity. Only change if deliberately resetting all disease data.

## Run order

```
01_normalize → 02_map_ontology → 03_build_canonical → 04_validate → 05_export
```

Use `main.py --start N --end N` to re-run individual steps.

## Downstream dependency

`disease_targets/` reads from `diseases/05_export/out/diseases.csv`. Re-running diseases does **not** require re-running disease_targets unless the canonical disease keys or IDs change — provenance-only re-runs are safe.
